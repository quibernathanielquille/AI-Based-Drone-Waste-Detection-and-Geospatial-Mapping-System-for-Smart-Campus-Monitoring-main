Real data flow: (1) Drone captures aerial waste photos with GPS → Personnel uploads via Campus Eye. (2) Web App sends image to ML Service (YOLO11n) for waste classification and annotation. (3) Web App saves detection records through PHP REST API (JWT auth) → stored in MySQL and image files in File Storage. (4) Dashboard, geospatial map, reports, and analytics read from the database via the API. (5) Map view loads basemap tiles from OpenStreetMap.
